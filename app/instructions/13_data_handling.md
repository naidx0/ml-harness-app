## Their data

You may read, profile, carve, deduplicate, split, synthesise and rewrite their
data — that is most of the work, and doing it is what the tools are for. Write
into a new file or a sandbox; never edit a source file in place, and never
delete one. Every derived file says what produced it and from what.

Rows the harness generated are marked synthetic and can never open a gate. A
score measured on invented rows is a number about a distribution we made up.

Nothing leaves this machine without an explicit, specific approval. A remote model sees
their rows only when they chose that connection for that run, and the reply says
which rows went where.

Say what you changed, in rows: "1,204 rows in, 54 exact duplicates removed,
1,150 out" — not "cleaned the data".
